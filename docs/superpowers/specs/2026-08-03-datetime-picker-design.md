# 记账页日期时间选择器 设计文档

日期：2026-08-03
状态：已批准

## 1. 动机

当前记账页的 `BookingPage.vue` 在提交交易时，日期和时间字段直接使用 `new Date()` 获取当前系统时间，用户无法修改。当需要补录历史交易（例如第二天补记前一天的消费）时，用户只能先以当前时间提交，再进入明细页编辑修改，流程繁琐。

在编辑表单（`TransactionEdit.vue`）中已存在日期时间输入（使用原生 `<input type="date">` / `<input type="time">`），但记账页作为最核心的录入入口，应该直接支持日期时间选择。

## 2. 目标

- 为记账页添加日期+时间选择功能，支持补录历史交易
- 与现有自定义组件风格一致（数字键盘、分类选择器等）
- 默认值仍为当前时间，尽量减少对快速记账流程的干扰

## 3. 设计方案

### 3.1 UI 位置

在金额显示区与分类选择器之间，新增一行日期时间显示条：

```
┌─────────────────────────┐
│      ¥ 1,280.00         │  ← 金额（现有）
│                         │
│  📅 今天 15:30       ›  │  ← ★ 新增：日期时间显示
│                         │
│  餐饮  交通  购物        │  ← 分类选择器（现有）
└─────────────────────────┘
```

- 右侧 `›` 箭头暗示可点击
- 显示规则：今天显示"今天 HH:mm"，昨天显示"昨天 HH:mm"，其余显示"M月D日 HH:mm"
- 整条可点击，点击弹出选择器

### 3.2 选择器组件：DateTimePicker

复用项目中已有的 `CommonBottomSheet.vue` 作为容器，构建一个自定义日期时间选择器。

**容器**：`CommonBottomSheet`（Teleport 到 body，遮罩层 + 底部弹出面板）

**顶部操作栏**：
- 左侧 ✕（取消，回退到之前的选择）
- 中间 "选择日期和时间"
- 右侧 ✓（确认当前选择）

**日期区**：
- 月份导航：◀ 2026年8月 ▶（左右箭头切换月份）
- 日期芯片：横滑展示当月所有日期，每项显示 `日期+星期`（如 `3 一`、`4 二`）
- "今天"高亮标记，选中态有视觉反馈

**时间区**：
- 时/分两列，各自带上下微调按钮（▲/▼）
- 小时范围 00-23，分钟范围 00-59
- 分钟步长为 1（不使用 5 分钟步长，保留精确性）

**快捷按钮**：
- "设为今天"：一键将日期时间重置为当前系统时间

### 3.3 交互流程

1. 用户点击日期时间显示条 → 弹出 `DateTimePicker` 底部面板
2. 选择器初始值 = 当前页面已选日期时间（默认当前时间）
3. 用户选择日期和时间
4. 点击 ✓ 确认 → 关闭选择器，更新显示文本
5. 点击 ✕ 或遮罩层 → 取消，回退到之前的选择
6. "设为今天" → 日期时间重置为当前时刻

### 3.4 数据流

```
BookingPage.vue
  ├── selectedDate: string (YYYY-MM-DD)    ← v-model:date
  ├── selectedTime: string (HH:mm)         ← v-model:time
  │
  ├── DateTimePicker.vue
  │     props: date, time, visible
  │     emits: update:date, update:time, close
  │
  └── handleConfirm()
        └── 使用 selectedDate + selectedTime
            替代 new Date() 提交交易
```

- `selectedDate` 和 `selectedTime` 初始化值为当前系统时间
- 当用户修改记账模式（expense/income/transfer）时，**不清除**日期时间选择（与金额、分类等字段的重置行为不同）
- 提交交易后，日期时间**重置**为当前系统时间（与其他字段一致）

### 3.5 验证规则

- 不允许选择未来日期（防止统计异常）
- 时间可以任意选择，无业务限制

### 3.6 与编辑表单的关系

- 记账页的时间选择器：自定义底部面板，风格统一
- 编辑表单的时间输入：保持原生 `<input type="date">` / `<input type="time">` 不变
- 两者不共享组件实现，但共享相同的日期/时间格式（YYYY-MM-DD / HH:mm）

## 4. 文件变更清单

| 文件 | 操作 | 说明 |
|---|---|---|
| `src/pages/booking/BookingPage.vue` | 修改 | 新增日期时间显示条 + selectedDate/selectedTime 状态 + 提交逻辑 |

| 无需新增依赖 | - | 复用 CommonBottomSheet.vue、现有类型、现有 format 工具函数 |

## 5. 边界情况

- **未来日期**：不允许选择，日期芯片中未来的日期置灰不可选
- **跨月导航**：左右箭头切换月份时，如果当前选中日在新月中不存在（如 1月31日 → 2月），自动调整到该月最后一天
- **小时/分钟数值越界**：微调按钮在边界（00/23, 00/59）时禁用
- **时间格式显示**：统一使用 HH:mm 两位小时和分钟
